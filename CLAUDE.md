## Project Context

**Stack:** TypeScript library (zero dependencies), Aho-Corasick based profanity checker
**Package manager:** pnpm
**Primary language:** TypeScript

---

## Project Structure

```
src/
  index.ts       ← Public API entry point
  checker.ts     ← ProfanityChecker class (find/censor/isProfane, addWords/removeWords)
  automaton.ts   ← Aho-Corasick automaton (O(n) scanning core)
  normalizer.ts  ← Text normalization (leet-speak, separators, diacritics)
  types.ts       ← Shared types
  lists/         ← Per-language wordlists (en, es, fr, de) + index
test/
  checker.test.ts ← Unit tests (vitest)
  bench.test.ts    ← Benchmark tests
site/
  index.html     ← Live demo page
  main.ts        ← Demo logic (source of truth — edit this, not the bundle)
  bleepit.bundle.js ← Built output; regenerate with `pnpm site:build`, don't hand-edit
```

---

## Component & Code Reuse

- Check `src/lists/` before adding new profanity entries — extend the relevant language file
- Extend `ProfanityChecker` (`src/checker.ts`) rather than adding parallel detection logic
- Extract logic used in 2+ places into a shared helper in `src/normalizer.ts` or `src/automaton.ts`
- Inline logic stays inline until it recurs

---

## Stack Conventions

- No runtime dependencies — keep it that way (this is a core selling point: "zero dependencies, isomorphic")
- Public API surface is exported from `src/index.ts`; keep internals (automaton, normalizer) unexported unless needed
- `dist/` is generated via `tsup` (`pnpm build`) — never hand-edit or commit ad hoc changes there
- `site/bleepit.bundle.js` is generated via `esbuild` (`pnpm site:build`) — edit `site/main.ts`, then rebuild

---

## Git Scopes

Use these scopes in commit messages:

- `(checker)` — ProfanityChecker core logic (find/censor/isProfane)
- `(automaton)` — Aho-Corasick automaton
- `(normalizer)` — Text normalization (leet, separators, diacritics)
- `(lists)` — Wordlist additions/changes per language
- `(site)` — Live demo page
- `(config)` — Build/config/tooling

---

## Off Limits

- Don't hand-edit `dist/` — it's generated by `pnpm build`
- Don't hand-edit `site/bleepit.bundle.js` — it's generated by `pnpm site:build` from `site/main.ts`

## Commands to Know

```bash
pnpm build        ← Build the library (tsup)
pnpm test         ← Run tests before committing (vitest)
pnpm test:watch   ← Watch mode for tests
pnpm bench        ← Run benchmark suite
pnpm site:build   ← Rebuild the live demo bundle after editing site/main.ts
pnpm lint         ← Type-check (tsc --noEmit)
pnpm size         ← Build and report gzip size of dist/index.js
```
